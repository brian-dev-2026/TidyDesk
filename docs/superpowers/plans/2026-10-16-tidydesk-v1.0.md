# TidyDesk v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship TidyDesk 1.0.0. It adds auto-update, exclusions, a Large Files page, an Empty Folders page, scheduled auto-clean, organizer options, drag & drop, and an error log with CSV export. It also fixes the Ctrl+R / Ctrl+W window glitch.

**Architecture:**
- New logic lives in small, Electron-free modules under `src/main/`, tested with Vitest against real temporary folders.
- The modules are wired through `ipc.ts`, `preload` and React pages, following the v0.1 patterns.
- The Safe Bin, history, dry run and protected-path rules are reused unchanged.

**Tech Stack:** as in v0.1. New: `electron-updater@6`. Windows notifications use Electron `Notification`.

**Spec:** `docs/superpowers/specs/2026-10-16-tidydesk-v1.0-design.md`. The base spec `2026-10-16-tidydesk-design.md` still applies.

## Global Constraints

- **Everything from the v0.1 plan still holds:**
  - The Safe Bin is the only permanent-delete path for user files. The Recycle Bin code is the only other.
  - Dry run never touches disk.
  - The scheduler does nothing before `firstRunNoticeSeen`.
  - IPC is accepted only from the app page.
- **Exclusions:** checked at scan time and again at action time. Excluded items are skipped with reason `EXCLUDED`.
- **New settings and their defaults:**
  - `autoDownloadUpdates: true`
  - `exclusions: []` (at most 200 entries)
  - `autoClean: 'off'`
  - `autoCleanCategories: ['user-temp','windows-temp','thumbnails','crash-dumps']`
  - `lastAutoClean` unset
  - `organizerCategories` unset
  - `organizeMode: 'type'`
- **Large files:** defaults are `minSize` = 50 MB (52428800 bytes) and `limit` = 200.
- **Empty folders:** never include the root, hidden or system folders, `.git`, or `.tidydesk-bin`. A folder is removed only with `rmdir`, after re-checking it is empty.
- **Updater:** active only when `app.isPackaged`. Checks 10 s after start, then every 21600000 ms (6 h).
- **Auto-clean intervals:** daily = 86400000 ms, weekly = 604800000 ms.
- **Log:** `<userData>\logs\tidydesk.log`, rotated at 1048576 bytes, keeping 3 files.
- **CSV columns:** `date,action,title,status,dry_run,path,destination,size_bytes,item_state,reason`.
- **Version:** 1.0.0, Semantic Versioning from then on.

## Review Focus

1. **A path excluded *after* a scan but before the action.** The action skips it (`EXCLUDED`). *Test: Task 3 `quarantine skips paths excluded at action time`.*
2. **A folder that gains a file between the empty-folder scan and removal.** It is not removed. *Test: Task 5 `does not remove a folder that is no longer empty`.*
3. **A Large Files scan of a drive root.** System folders are not entered, and the scan finishes. *Test: Task 4 `skips protected folders when scanning a drive root`.*
4. **Date-mode organize, then undo.** The original layout is restored and nested year/month folders are removed. *Test: Task 6 `date mode apply then undo round-trip`.*
5. **A user-edited category table that is invalid** (duplicate extension, a reserved or illegal name). It is rejected before saving. *Test: Task 6 `validateCategories rejects …`.*
