# TidyDesk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build TidyDesk, a Windows Electron app that cleans junk, organizes folders and removes duplicate files. Every removal is held in a restorable Safe Bin for 5 hours, and the app ships as an NSIS installer.

**Architecture:**
- **Main process:** all file-system logic lives in small, Electron-free modules under `src/main/`. They're unit-tested with Vitest against real temporary folders, and the main process wires them to IPC.
- **Preload:** exposes a typed `window.tidy` API.
- **Renderer:** React with Tailwind. It only renders the UI and calls that API.

**Tech Stack:**
- Electron 33, electron-vite 2, React 18, TypeScript 5, Tailwind CSS 3, lucide-react
- Vitest 2 for tests, electron-builder 25 (NSIS) for packaging, GitHub Actions for CI

**Spec:** `docs/superpowers/specs/2026-10-16-tidydesk-design.md`

## Global Constraints

- **Platform:** Windows only (build, test and target). Node 24 locally, Node 20 in CI.
- **Renderer security:** `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`.
- **Deleting user files:** the Safe Bin is the only module that may permanently delete user files (`fs.rm`), apart from the Recycle Bin code (`recyclebin.ts`).
- **Hold time:** `holdHours` defaults to 5 and applies to both the Safe Bin and the Windows Recycle Bin sweep.
- **Default settings:**
  - `theme: 'system'`
  - `holdHours: 5`
  - `sweepWindowsRecycleBin: true`
  - `minDuplicateSize: 1024`
  - `closeToTray: true`
  - `startWithWindows: false`
  - `firstRunNoticeSeen: false`
  - `dryRun: false`
- **Dry run:** when `dryRun` is on, nothing on disk may change: no move, rename, delete or mkdir. Each action still records a history entry with `dryRun: true` and status `simulated`, and the scheduler neither purges nor sweeps.
- **App data:** stored in `app.getPath('userData')`, which is `%APPDATA%\TidyDesk`.
- **History file:** `history.json`, capped at 500 entries. Lists longer than 2,000 items go to sidecar files at `history/<id>.json`.
- **Safe Bin location:** `<driveRoot>\.tidydesk-bin\<batchId>\`, with the hidden attribute set.
- **Protected paths:** `C:\Windows`, `C:\Program Files`, `C:\Program Files (x86)`, `C:\ProgramData`, any drive root, and anything inside a `.tidydesk-bin` folder.
- **Junk scan:** skips files modified less than 1 hour ago.
- **Duplicate matching:** size, then a 64 KB head hash, then the full SHA-256.
- **Progress events:** at most 10 per second.
- **Window:** 1100×720 by default, 900×600 minimum, frameless.
- **Installer:** artifact name `TidyDesk-Setup-${version}.exe`. NSIS is not one-click, lets the user change the install directory, and creates desktop and Start Menu shortcuts.
- **Licence:** MIT.

## Review Focus

1. **Restore after the original folder was deleted or moved.** The user expects the file back at its original path, with the folders recreated. *Test: Task 3 `restore recreates missing parent dirs`.*
2. **Two files with the same name from different folders in one batch.** Neither must overwrite the other inside the bin. *Test: Task 3 `same basenames do not collide in bin`.*
3. **App closed while a batch expires.** The next startup purges every overdue batch. *Test: Task 3 `purgeExpired purges overdue batches on startup`.*
4. **Scanning a tree that contains a junction loop or a Safe Bin folder.** The scan finishes and never lists files from the bin. *Tests: Task 5 `does not follow junctions` and `skips .tidydesk-bin`.*
5. **Dry run left on while the scheduler fires.** No purge or sweep may run, or a "safe test" would permanently delete things. *Test: Task 7 `tick does nothing in dry run`.*
6. **A top-level file whose name matches a category folder** (for example a file called `Images` with no extension). Organize must not crash; that file is left out of the plan. *Test: Task 4 `skips files named like a category folder`.*

### Task 3: Safe Bin

**Files:**
- Create: `src/main/safebin.ts`
- Test: `tests/main/safebin.test.ts`

**Interfaces:**
- Consumes: `HistoryStore`, `moveFile`, `uniquePath`
- Produces:
```ts
interface SafeBinOpts { history: HistoryStore; holdHours: () => number; binRootFor?: (file: string) => string; now?: () => number }
class SafeBin {
  constructor(o: SafeBinOpts)
  quarantine(files: string[], meta: { type: 'junk' | 'duplicates'; title: string; dryRun?: boolean }, onProgress?: (done: number, total: number) => void): Promise<HistoryEntry>
  restore(entryId: string, paths?: string[]): Promise<HistoryEntry>   // paths = originalPath subset; default all held
  purge(entryId: string): Promise<HistoryEntry>                        // permanently deletes held items, status 'purged', purgedAt set
  purgeExpired(): Promise<number>                                      // purges every held/partial entry with expiresAt <= now(); returns count
  heldBytes(): Promise<number>
  orphans(roots: string[]): Promise<{ binDir: string; bytes: number }[]>   // batch folders under each root's .tidydesk-bin with no history entry
  deleteOrphan(binDir: string): Promise<void>                             // only accepts a direct child of a .tidydesk-bin folder
}
```
- **Default `binRootFor`:** `path.parse(file).root + '.tidydesk-bin'`. On first creation, run `attrib +h` on it (ignore failure). If `mkdir` fails, fall back to `path.parse(os.homedir()).root + '.tidydesk-bin'`.
- **Bin path:** `<binRoot>\<entryId>\<index>_<basename>`.
- **Status rules:**
  - Every held item restored: `restored`.
  - Some items restored and some still held: `partial`.
  - After a purge: `purged`.
  - `expiresAt = createdAt + holdHours * 3600000`.
- **Skipped files:** a file that fails to move is recorded with `state: 'skipped'` and a `reason` (the error code). `skipped` counts these items, and `bytes` and `count` cover only the items that moved.
- **Dry run:** `quarantine` with `dryRun: true` only runs `stat` on each file. It records items with `state: 'would-remove'` and `binPath: ''`, status `simulated`, `dryRun: true` and no `expiresAt`, and creates no bin folder. `restore` and `purge` on a simulated entry throw `Error('Dry run entry')`, and `purgeExpired` ignores simulated entries.
- **Restore conflict:** if the original path is now occupied, restore to `uniquePath` with the suffix ` (restored)`, giving `name (restored).ext`.

### Task 5: Duplicate finder

**Files:**
- Create: `src/main/duplicates.ts`
- Test: `tests/main/duplicates.test.ts`

**Interfaces:**
- Consumes: `walkFiles`, `isProtectedPath`
- Produces: `findDuplicates(dir: string, opts: { minSize: number; signal?: AbortSignal; onProgress?: (p: { phase: 'listing'|'hashing'; done: number; total: number }) => void }): Promise<DupGroup[]>`
- **Algorithm:**
  1. Walk the folder with `skipHidden: false` and keep files with `size >= minSize`.
  2. Bucket by size and drop buckets with only one file.
  3. Compute the SHA-256 of the first 65,536 bytes and re-bucket by `size:headHash`.
  4. Compute the full SHA-256 as a stream and re-bucket.
  5. Return groups with 2 or more files, each group's files sorted by `mtimeMs` ascending, and groups sorted by `size * (files.length - 1)` descending.
- **Read errors:** a file that can't be read during hashing is dropped silently.
- **Cancelling:** when `signal` is aborted, throw `Error('Cancelled')`.
- **Protected folders:** throw `Error('Protected folder')`.

  - `finds identical content with different names across subfolders`.

  - `same first 64KB but different tail is not a duplicate`: two 100 KB buffers that differ in the last byte.
  - `respects minSize`.
  - `empty folder returns []`.
  - `does not follow junctions`: create a junction loop and check that no duplicate group comes from the junction path.
  - `skips .tidydesk-bin`: a copy inside the bin is not reported.
  - `abort throws Cancelled`.

- **Sweep script.** Item-level errors are caught and that item is skipped.
```powershell

$rb=(New-Object -ComObject Shell.Application).Namespace(10)
foreach($i in @($rb.Items())){ try {
  $d=$i.ExtendedProperty('System.Recycle.DateDeleted')
  if($d -and ([datetime]$d) -lt $cutoff){
    $p=$i.Path; $s=[int64]$i.ExtendedProperty('Size')
    $info=Join-Path (Split-Path $p) ('$I'+(Split-Path $p -Leaf).Substring(2))
    Remove-Item -LiteralPath $p -Recurse -Force -ErrorAction Stop
    Remove-Item -LiteralPath $info -Force -ErrorAction SilentlyContinue
    $n++; $b+=$s } } catch {} }
@{count=$n;bytes=$b}|ConvertTo-Json -Compress
```
  The info script uses the same loop, without the date filter, and only adds up the count and size.
- **Scheduler `tick()`:**
  0. If `settings.dryRun` is on, return without doing anything.
  1. Run `safeBin.purgeExpired()`.
  2. If `sweepWindowsRecycleBin` is on, call `sweep(holdHours)`. If its count is greater than 0, add a history entry with type `recycle-sweep`, status `done`, and title `Recycle Bin: ${count} items older than ${h}h permanently deleted`.
  3. Call `onChange()` if anything changed.
  4. Catch and log every error; `tick()` never throws.
- **Timing:** `startScheduler` runs `tick()` immediately, then every `intervalMs`, which defaults to 300000.
